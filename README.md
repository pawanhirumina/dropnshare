# Drop & Share

- This is a project i made during my IT Diploma to share files without login into any accounts or any sites and access them whenever i want
with just 3 clicks.

### How it works

- first user uploads a file to the web app 
- uploaded files last 24 hours and it gives the user a 6 digit 
- then user can paste the code into the download prompt and download the file

### Tech Stack

- NextJs (Framework)
- TailwindCSS (Styling)
- Supabase (Backend Service)
- ShadcnUi (Ui Components)
